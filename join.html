    // 02 — Step by step

    Connect to the server

    Pick your launcher. If the server uses mods, the DZSA Launcher is the easiest way – it downloads and loads everything for you.

    1. Start DayZ

      Launch DayZ through Steam. The official DayZ Launcher opens.

    2. Open the server browser

      Go to Servers and select the Community tab.

    3. Find Project Blackout

      Type Project Blackout into the search field. Can't find it? Use Direct connect and enter

    4. Download mods (if required)

      If the server needs mods, the launcher offers to subscribe to them in the Steam Workshop. Wait until all downloads are finished.

    5. Join

      Click Play – see you on the coast.

    1. Install the DZSA Launcher

      Download it for free from dayzsalauncher.com and install it.

    2. Start the launcher

      It finds your DayZ installation automatically. Make sure Steam is running.

    3. Search for the server

      Enter Project Blackout in the search bar of the server list.

    4. Play

      Click Play. Missing mods are downloaded and loaded automatically – the first start can take a few minutes.

    // 03 — Survival basics

    Your first hour

    New to DayZ or to hardcore PvP? These habits keep you alive longer.

    Water & food first

    Wells, ponds and canned food in houses keep you going. Don't drink from dirty water without boiling it.

    Grab a melee weapon

    An axe or a pipe wrench beats bare fists against infected – and against other fresh spawns.

    Move inland

    The coast is crowded. Head inland, avoid open fields and use tree lines for cover.

    Light discipline

    At night, every flashlight and chemlight gives away your position. Use them only when you have to.

    Check before you loot

    Stop, listen and scan before entering a town. Open doors and gunshots mean someone was here.

    Find a squad

    Lone wolves die fast. Look for teammates on our Discord.

    // 04 — Troubleshooting

    Can't connect?

    The most common problems and how to fix them.

    The server doesn't show up in the list

    Clear all filters in the server browser (ping, version, “show full servers”) and search again. If it still doesn't appear, use Direct connect with the server IP. The server might also be restarting – check the restart schedule.

    “Missing mods” or mod mismatch

    Use the DZSA Launcher, or let the official launcher download the mods. If the error persists, unsubscribe from the affected mod in the Steam Workshop, subscribe again and wait until Steam has finished downloading.

    Kicked by BattlEye

    Restart Steam and DayZ. If that doesn't help, verify your game files: Steam → DayZ → Properties → Installed Files → Verify integrity of game files. This also repairs BattlEye. Close overlay or macro software that BattlEye might flag.

    Version mismatch

    Update DayZ through Steam. After big game updates the server may need some time to update too – watch Discord for announcements.

    Stuck on the loading screen

    Verify your game files and give it a moment – the first join after a restart takes longer. Installing DayZ on an SSD speeds up loading considerably.

    Still stuck? Check the FAQ or open a support ticket – we'll help you get in.
